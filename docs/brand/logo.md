# 项目标志：叠色印章

以三张错位色卡构成印章轮廓，表达中国传统色的整理、搭配与使用。朱红为印面，石青为底片，米白为纸张；印面内三道留白与金色小块构成抽象色卡清单。

## 唯一母版

根目录 `favicon.svg` 是唯一可编辑图形源文件。所有形状均为路径，不依赖字体、外链或位图。导航栏和浏览器优先使用 SVG。

## 生成图片

需要 Node.js 及 npm：

```bash
npm install
npm run brand:build
```

输出位于 `assets/brand/`：

- `icon-16.png`、`icon-32.png`、`icon-48.png`：小尺寸图标。
- `icon-180.png`：Apple Touch Icon。
- `icon-192.png`、`icon-512.png`：应用图标。
- `icon-1024.png`：高清展示或项目头像。
- `favicon.ico`：包含 16、32、48 像素 PNG 帧的兼容图标。

所有 PNG 使用透明背景，保留叠片间的留白；ICO 同样由母版导出的 PNG 组装。修改标志时只修改 SVG，再运行导出命令，避免各格式产生差异。

## 使用规范

保留原始正方形画布及内置留白，不拉伸、不旋转、不另加阴影或渐变。明暗主题使用同一份彩色标志。推荐最小展示尺寸 16px，导航栏使用 40px。

颜色：朱红 `#B64036`、石青 `#277A7B`、米白 `#F2E6CE`、暖白 `#FFF8EB`、金色 `#D8AF58`。

# 项目标志：四色花

四片完全相同的花瓣围绕画布中心，分别旋转 0°、90°、180°、270°，构成旋转对称的四色花。石青、朱红、杏黄、灰绿分别对应一片花瓣，暖米白圆角底板统一轮廓。所有花瓣复用同一条路径，只改变旋转角度和填色。

## 唯一母版

根目录 `favicon.svg` 是唯一可编辑图形源文件。图形由矢量路径和圆角矩形组成，不依赖字体、外链或位图。导航栏和浏览器优先使用 SVG。

## 生成图片

需要 Node.js 及 npm：

```bash
npm install
npm run brand:build
```

输出位于 `assets/brand/`：

- `icon-16.png`、`icon-32.png`、`icon-48.png`：小尺寸图标。
- `icon-180.png`：Apple Touch Icon。
- `icon-192.png`、`icon-512.png`：应用图标。
- `icon-1024.png`：高清展示或项目头像。
- `favicon.ico`：包含 16、32、48 像素 PNG 帧的兼容图标。

所有 PNG 保留暖米白底板与画布外缘的透明区域；ICO 同样由母版导出的 PNG 组装。修改标志时只修改 SVG，再运行导出命令，避免各格式产生差异。

## 使用规范

保留原始正方形画布及内置留白，不拉伸、不旋转、不另加阴影或渐变。明暗主题使用同一份彩色标志。推荐最小展示尺寸 16px，导航栏使用 40px。

颜色：石青 `#315E50`、朱红 `#BC5844`、杏黄 `#D7AE6B`、灰绿 `#86A58D`；底板为暖米白 `#EFE9DD`。
